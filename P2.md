# ОТЧЕТ ПО ПРАКТИЧЕСКОЙ РАБОТЕ № 6
### Дисциплина: МДК.04.01 Внедрение программного обеспечения
### Тема: План внедрения ИС «Электронный журнал группы» (EduJournal)

---

## ВВЕДЕНИЕ

**Цель работы:** Разработка пошагового плана внедрения веб-приложения «Электронный журнал группы» (EduJournal) на серверную инфраструктуру учебного заведения.

**Стек технологий системы:** 
 Язык Python 3.12, фреймворк Django 5.0 + Django REST Framework (DRF).
 База данных PostgreSQL 16, авторизация пользователей по JWT-токенам.
---

## ГЛАВА 1. АНАЛИЗ ПОТРЕБНОСТЕЙ И ПОСТАНОВКА ЗАДАЧИ

### 1.1. Задачи внедрения (Зачем внедряем систему)
*   **Автоматизация работы учителя:** Автоматический расчет средних баллов учащихся и быстрое формирование отчетов успеваемости.
*   **Ускорение информирования:** Мгновенный доступ родителей и студентов к расписанию, оценкам и домашним заданиям.
*   **Отказ от бумажных носителей:** Замена ветхих бумажных ведомостей надежной цифровой базой.

### 1.2. Роли пользователей
*   **Администратор:** Управляет учетными записями, заводит новые группы, предметы и пользователей.
*   **Преподаватель:** Выставляет оценки, отмечает посещаемость, загружает домашние задания.
*   **Студент / Родитель:** Просматривает расписание, дедлайны и личную успеваемость в режиме чтения.
---

## ГЛАВА 2. СТРУКТУРА ПРОЕКТА И НАСТРОЙКА

### 2.1. Структура каталогов репозитория
Проект состоит из следующих основных компонентов:
*   `apps/accounts` — модуль регистрации и авторизации пользователей.
*   `apps/catalog` — справочники предметов и расписания.
*   `apps/clients` — базы данных студентов, преподавателей и групп.
*   `apps/reports` — модуль расчета среднего балла и ведомостей.
*   `config/settings.py` — общие настройки Django-приложения.

### 2.2. Порядок установки на сервере
1.  **Клонирование проекта и установка библиотек:**
    ```bash
    cd edujournal
    python -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt
    ```
2.  **Настройка конфигурации файла `.env`:**
    ```env
    DEBUG=False
    SECRET_KEY=secure-edujournal-key-xyz
    DB_NAME=edujournal_db
    DB_USER=journal_db_admin
    DB_PASSWORD=secure_postgres_pass
    ```
3.  **Применение миграций базы данных:**
    ```bash
    python manage.py migrate
    python manage.py createsuperuser
    ```

## ГЛАВА 3. КАЛЕНДАРНЫЙ ПЛАН И МИГРАЦИЯ ДАННЫХ

### 4.1. Календарный план проекта (Срок: 15 дней)
Процесс развертывания разбит на 15 рабочих дней:
*   **Дни 1–2:** Анализ потребностей. Сбор списков учебной части, проверка готовности серверов.
*   **Дни 3–4:** Подготовка платформы. Установка и настройка СУБД PostgreSQL на сервере.
*   **Дни 5–7:** Установка и деплой ПО. Перенос кода на сервер, настройка конфигурации `.env`, запуск миграций.
*   **Дни 8–9:** Миграция данных. Создание бэкапов, перенос архивных баз данных в новую систему.
*   **Дни 10–12:** Тестирование и отладка. Запуск тестов, проверка авторизации, поиск ошибок.
*   **Дни 13–15:** Обучение и запуск. Инструктаж учителей, запуск пилотных групп в работу.

### 4.2. Ресурсы и ответственные
*   **Системный администратор:** Отвечает за установку ПО, СУБД PostgreSQL и создание резервных копий.
*   **Руководитель проекта:** Отвечает за общую координацию и соблюдение 15-дневного срока.
*   **Специалист поддержки:** Отвечает за обучение пользователей и обработку обратной связи.
*   **Ресурсы:** Компьютеры, сервер, интернет, бюджет, электричество.

### 4.3. Регламент миграции данных
1.  **Сохранение резервной копии:** Настройка регулярных дампов базы данных PostgreSQL с отправкой бэкапов в облако для защиты от потери информации:
    ```
    pg_dump -U journal_db_admin -d edujournal_db -b -v -f /backups/init_dump.sql
    ```
2.  **Перекачка данных:** Загрузка списков студентов и преподавателей в базу нового ПО через встроенный REST API (`POST`-запросы).

### 4.4. Риски проекта и их минимизация
*   *Перебои интернета:* Настройка резервного 4G-канала связи.
*   *Нехватка денег или времени:* запуск только оценок и посещаемости на первом этапе.
*   *Перебои электричества:* Подключение серверов к источникам бесперебойного питания (ИБП).
